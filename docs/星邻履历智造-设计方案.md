# 星邻履历智造 · 设计方案文档

> 作品名：星邻履历智造（StarLink Resume Maker）  \
> 作者：张宏健（示例）  \
> 联系方式：138-0000-0000 / example@email.com

## 1. 项目背景与问题陈述

### 1.1 新兴市场调研亮点
- **硬件与网络**：GSMA 2024 报告显示，撒哈拉以南地区 60% 智能机为入门级，主要运行 2G/3G，平均带宽不足 10Mbps；功耗与弱网成为移动 AI 应用最大瓶颈。
- **语言环境**：非洲超 2000 种语言，26% 用户日常对话混合英语与本地语（传音内部调研，n=300）。
- **数字素养**：非正规经济人群普遍缺乏桌面办公经验，约 70% 不会使用 Word 模板制作简历（街头访谈 17 人，2024.11，拉各斯）。

### 1.2 用户痛点与机会
1. **制作门槛高**：求职者手头多为散乱的 docx/语音/截图，缺乏结构化表达能力。
2. **AI 工具不可用**：主流生成式工具网络/算力要求高，且不支持混合语言、深肤色视觉优化。
3. **隐私担忧**：个人履历涉及身份证明、电话等信息，用户不信任纯云端存储。

### 1.3 目标
打造一个“AI+就业”方案，让低数字素养、弱网、低算力用户也能 **上传原始简历 → AI 结构化解析 → 模板排版 → 导出/分享**，真正落地“有温度的 AI”。

## 2. 解决方案框架

### 2.1 系统构成（模块文字示意）
1. **介绍入口**：`简介页面.html`，讲述产品价值并引导进入 `/app/` React 应用。
2. **前端应用层**（Gatsby/React）：
   - `ExperienceTable` + `AISummaryPanel`：上传、解析、编辑经历。
   - `Resume` 模板组 + `LangSwitcher`：主题切换、语言切换、PDF 导出。
3. **AI 解析服务**（`server/local-api.js`）：统一 Prompt，代理 DeepSeek/Gemini，输出 `ExperienceItem[]`。
4. **数据层**：`data/experiences.json`、`data/resume.json`、`localStorage`，本地优先，支持小型云端同步。
5. **部署层**：`scripts/do-deploy.sh` 拉取代码、`pnpm build`、Nginx 提供 `/`（简介页）和 `/app/`（应用）。

### 2.2 交互流程图（文字描述）
1. 用户打开 `http://<IP>/` → 浏览简介页 → 点击“开始制作”。
2. 进入 `/app/experience`：上传 docx 或粘贴文本 → 请求 `/api/ai/summarize`。
3. 模型返回结构化经历 → 表格中可编辑标签、要点、时间。
4. 保存后写入 `experience.json`/localStorage → 前往 `/resume` 选择模板、主题、语言 → 导出 PDF/分享链接。
5. `/settings` 可配置 API Key、Prompt；`/profile` 管理个人信息；`/final` 预览最终版。

## 3. 技术实现路径

### 3.1 AI 模型与 Prompt
- **模型**：默认 DeepSeek（可切换 Gemini、多家 API）；`temperature=0.2`；`response_format=json`。
- **Prompt 模板**：详见 `docs/experience-ai-pipeline.md`，强调“仅返回 JSON”“1-3 标签”“补齐时间”。
- **标签体系**：量化研究/交易执行/数据工程… 共 8 类，支持 `TO_CONFIRM` 占位。

### 3.2 核心流程
1. **Docx 预处理**：mammoth/python-docx 识别 Heading+段落；正则匹配 `\d{4}[./-]\d{2}` 提取时间。
2. **AI 结构化**：`buildAiRequest` 拼装请求，支持 Gemini 特殊参数；输出 `ExperienceItem`。
3. **后处理**：校验 JSON、去重（key=`company+start`）、标记缺失字段。
4. **视图映射**：`ExperienceTable` → `RESUME_INFO.workExpList/projectList` → `Resume` 模板渲染。
5. **多语言与主题**：`IntlProvider` + `LangSwitcher`，模板支持 3 套主题，PDF 通过 `window.print()` 或 `react-to-print`。

### 3.3 数据与隐私
- 默认 `src/data/resume.ts` 仅保留结构，不含真实经历（已清空 `workExpList`/`projectList`）。
- 用户数据存储在本地 `localStorage`、`data/experiences.json`，可导出 JSON/上传 GitHub special 仓库。
- 后端仅作为代理，不保留个人信息；支持自签/内网部署。

## 4. 落地可行性评估

| 维度 | 方案 | 风险与缓解 |
| ---- | ---- | -------- |
| 硬件 | 前端静态站+Node 代理，1vCPU/1GB Droplet 可跑；客户端仅需 Chrome 63+ | 高并发可通过 CDN 扩展；移动端建议 PWA 缓存 |
| 网络 | Landing/应用分离，静态资源可 CDN；AI 请求可重试/排队；支持 docx 离线准备 | 极弱网时提供 “本地保存 JSON” 提示，待联网后提交 |
| 成本 | Droplet $6/月 + AI API；可切换自建模型或 DeepSeek 套餐 | 引入配额监控；提供端侧小模型计划 |
| 语言 | 内置中/英；Prompt 可指定输出语言；支持本地化 JSON | 增加语言包工具 `scripts/i18n-pick.js`，方便扩展 |
| 隐私 | 数据默认本地存储；API 不落盘；用户可导出 GitHub | 提供“匿名模式”与本地运行脚本，满足企业安全需求 |
